# Operaciones con matrices en Java / Matrix operations in Java

[Español](#español) · [English](#english)

## Español

Ejercicio de consola que muestra cómo un programa realiza cálculos con matrices, tablas de números organizadas en filas y columnas.

### Esta revisión

**2010-09-03 · Calcular y transponer matrices desde un menú.** Separa la representación de las matrices, sus operaciones y la interfaz de consola. El menú permite comparar suma, multiplicación y transposición sobre las mismas tablas de ejemplo.

### Cómo explorar el código

Instala un JDK y empieza en la clase principal de la edición que quieras explorar.

- [src/matriz.java](src/matriz.java)
- [src/operaciones_matriz.java](src/operaciones_matriz.java)
- [src/principal.java](src/principal.java)
